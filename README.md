# GABF — Ferramentas gratuitas para MEI e prestadores de serviço

Ferramentas e guias gratuitos, em português brasileiro, para microempreendedores individuais (MEI), microempresas (ME) e empresas de pequeno porte (EPP) optantes do Simples Nacional.

**Site ao vivo:** [meunomenaoejonny.github.io/gabf-mvp](https://meunomenaoejonny.github.io/gabf-mvp/)

## Guia NFS-e Nacional em Campinas

Guia completo e gratuito para a migração da NFS-e em Campinas para o padrão nacional, incluindo:

- **Checklist interativo** por etapa (outubro/novembro/dezembro 2026 e janeiro 2027)
- **Passo a passo do Emissor Nacional** — como acessar e emitir
- **Prazos oficiais** — 1º/10, 1º/11 (Simples), 1º/12/2026 e 1º/01/2027 (IBS/CBS)
- **Erros comuns e soluções** — acesso negado, conta gov.br bronze, ME/EPP tentando gov.br
- **Guia específico para MEI** — obrigatório desde 09/2023 (NT 2023.001)
- **Guia específico para Simples Nacional (ME/EPP)** — obrigatório a partir de 1º/11/2026 (Res. CGSN 191/2026)
- **Versão para imprimir** — checklist otimizado para impressão em A4/PDF

Acesse: [meunomenaoejonny.github.io/gabf-mvp/nfse-campinas/](https://meunomenaoejonny.github.io/gabf-mvp/nfse-campinas/)

## Modelos grátis para escritórios contábeis: NFS-e Nacional do Simples (1º/11/2026)

A partir de 1º/11/2026, ME e EPP do Simples Nacional emitem NFS-e somente pelo Emissor Nacional (Res. CGSN 191/2026).

- [Modelo de comunicado aos clientes do Simples](https://meunomenaoejonny.github.io/gabf-mvp/nfse-nacional/modelo-comunicado-clientes-simples/): e-mail, WhatsApp, lembrete de 29-30/10 e mensagem pós-1º/11, grátis
- [Planilha básica de triagem da carteira (CSV)](https://meunomenaoejonny.github.io/gabf-mvp/assets/planilha-triagem-basica-nfse-nacional.csv), grátis
- [Kit Virada NFS-e Nacional para escritórios](https://meunomenaoejonny.github.io/gabf-mvp/nfse-nacional/kit-escritorios-contabeis/): guia do cliente editável com a marca do escritório, 4 comunicados em DOCX, planilha XLSX completa e folha da primeira semana (R$ 97, garantia de 7 dias)

## Características

- **Gratuito** — sem mensalidade, sem cadastro obrigatório
- **Fontes oficiais** — Receita Federal, Portal NFS-e, Prefeitura de Campinas
- **Sem cookies** — contagem de visitas anônima via Abacus API
- **Não é assessoria** — material informativo que não substitui contador

## Tecnologia

Site estático hospedado no GitHub Pages. Sem backend, sem banco de dados. O contador de visitas usa a API pública [Abacus](https://abacus.jasoncameron.dev).
